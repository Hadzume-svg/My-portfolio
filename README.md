# David — портфолио (React + Vite)

## Запуск локально

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173`.

## Сборка для деплоя

```bash
npm run build
```

Готовые статические файлы появятся в папке `dist/` — их можно залить на любой хостинг
(GitHub Pages, Vercel, Netlify, обычный хостинг с загрузкой файлов).

## Что и где менять

- **`src/data/profile.js`** — имя, фото, стек языков, услуги, ссылки на соцсети,
  текст "обо мне". Меняешь один раз и обновляешь по мере необходимости.
- **`src/data/projects.js`** — список работ в портфолио. Чтобы добавить проект —
  скопируй один объект в массиве и заполни поля (`title`, `description`, `category`,
  `image`, `link`). Категория (`design` / `frontend` / `bot`) управляет фильтрами
  на сайте.
- **`public/`** — сюда кладёшь картинки проектов (скриншоты, превью) и указываешь
  путь к ним в `image` внутри `projects.js`, например `"/projects/my-shop.png"`.
- **`src/components/`** — сами блоки сайта (шапка, хиро, услуги, работы, обо мне,
  контакты). Трогать нужно, только если хочешь поменять структуру, а не контент.
- **`src/styles/global.css`** — все стили и цвета сайта.

## Деплой на GitHub Pages (быстрый вариант)

1. Залей проект в свой репозиторий на GitHub.
2. Установи пакет `gh-pages`: `npm install --save-dev gh-pages`
3. Добавь в `package.json` в `scripts`: `"deploy": "npm run build && npx gh-pages -d dist"`
4. Выполни `npm run deploy`.
5. Включи GitHub Pages в настройках репозитория (ветка `gh-pages`).
